# 《果實拾光 Fruitful Glow》—— 台灣小農格外品低溫鮮果乾與水果茶磚
> **萬能科技大學《創意發想與實踐》（11501）期中報告**  
> **授課教師：邱俊維 博士** | **實踐模式：100% 個人獨立微型創業專案**

---

## 📌 專案簡介
本專案為遵循行銷學理經典教材（凌政文 教授著《行銷企劃》圖 1-9）之五階段標準流程所推動之期中微型創業專案。以台灣在地「格外品」（因規格或表皮不符量販標準但風味極佳的水果）為核心原料，透過 40°C 低溫熱風慢烘工藝，打造「零砂糖、零防腐劑、零漂白劑」之天然果乾與冷泡水果茶磚。

透過 **Google Antigravity** 梳理學理架構並生成現代日系極簡靜態網頁（MVP 原型），結合 **GitHub Pages** 實現零伺服器主機成本之雲端公開部署。

## 📚 期中行銷企劃 SOP 階段成果摘要

### 階段 1：啟動與分析
1. **痛點與緣起**：
   - 市售果乾高糖、防腐劑與二氧化硫漂白劑氾濫。
   - 鮮果冷鏈宅配運費高達 180~220 元，微型創業門檻過高；常溫超取僅 60 元，保存期長。
   - 台灣優質格外品被棄置浪費，市售傳統包裝俗豔缺乏生活美學。
2. **PESTC 外部總體環境分析**：
   - **P (政治法律)**：食藥署推行 Clean Label 潔淨標籤，成分全透明化法規為優勢。
   - **E (經濟環境)**：百元級小確幸抗跌「口紅效應」，搭配 60 元超取大幅提升轉化。
   - **S (社會文化)**：減糖健身、辦公室健康果乾水風氣盛行。
   - **T (科技創新)**：小型低溫熱風循環烘乾技術普及，小批量純手工品質穩定。
   - **C (綠色環保)**：拯救格外品減少食物浪費，支持在地契作縮短食物里程。
3. **假想敵防護之道**：
   - 假想敵：量販賣場平價進口蜜餞與超商化學果乾。
   - 防禦策略：不打低價戰，主打 100% 原切果肉纖維與每週鮮烘，構建安心品質護城河。
4. **SWOT 因果推論四象限**：
   - **SO 積極開拓**：敏捷架站結合「#辦公室果乾水挑戰」社群擴散。
   - **WO 借力補強**：以每週限量預購將產能限制轉化為新鮮稀缺優勢。
   - **ST 防禦轉化**：QR Code 全面公開小農履歷與零添加檢驗報告。
   - **WT 避險聚焦**：資金 3~5 萬嚴控周轉，專注厚切鳳梨乾與芭樂四季春兩大單品。

### 階段 2：目標與定位
- **SMART 目標**：上線 30 天內達成 200 次瀏覽、收集 30 份試吃預購登記。
- **三超思維**：超前意識（先以低風險常溫果乾切入驗證）、超越常規（開發冷泡果茶磚）、超越期望（隨包附贈每日飲水補水紀錄小卡）。
- **STP 品牌主張**：「果實拾光，把大地的純粹甜美帶進你的生活。」

### 階段 3：方案發想與設計 (4P 行銷組合)
- **產品 (Product)**：
  1. 【晨光金燦】厚切無糖金鑽鳳梨乾（80g / NT$ 140）
  2. 【山嵐清甜】紅心芭樂四季春冷泡茶磚（8 入 / NT$ 150）
  3. 【拾光隨行】Tritan 輕量冷泡果乾隨行瓶（500ml / 加購價 NT$ 180）
- **價格 (Price)**：早鳥嚐鮮 3 件特惠組 NT$ 399（均價百元好入手）。
- **通路 (Place)**：GitHub Pages 品牌型錄展示，串接 Google 表單，全台常溫超取 60 元。
- **推廣 (Promotion)**：「#辦公室果乾水打卡」短影音徵集與校園早鳥試吃分享。
